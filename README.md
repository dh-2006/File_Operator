# 📔 File Operator

> A beginner-friendly Python project that uses file handling and a simple menu-driven program to manage personal journal entries.

---

## 📌 Project Overview

**File Operator** is a Python project created to practice file handling and basic object-oriented programming.

The system allows users to:
- ✍️ Add a new journal entry
- 📖 View all saved entries
- 🔎 Search entries by keyword or date
- 🗑️ Delete all entries after confirmation

---

## 🎯 Objective

The objective of this project is to understand and implement:
- Classes and objects
- File handling using `open()`, `read()`, `write()` and `close()`
- Date and time using `datetime`
- Exception handling using `try-except`
- Basic input validation using `if-else`
- A menu-driven console interface

---

## 🧩 Concepts Used

| Concept | Implementation |
|---|---|
| **Class** | `JournalManager` |
| **Object** | `journal` object |
| **File Handling** | Read and append journal entries in `journal.txt` |
| **Date and Time** | Add a timestamp to each entry |
| **Exception Handling** | Handle missing files and file errors |
| **Validation** | Check empty entries and invalid menu choices |
| **Loop and Conditions** | Keep the menu running until Exit is selected |

---

## 🖥️ Main Menu

```text
Welcome to Personal Journal Manager!

Please select an option:

1. Add a New Entry

3. Search for an Entry
4. Delete All Entries
5. Exit
```

---

## ⚙️ Features

- Add a new journal entry
- Automatically save date and time with each entry
- View all saved journal entries
- Search using a keyword or date
- Delete all entries after confirmation
- Validate empty entries and search terms
- Handle missing files and common file errors
- Simple menu-driven interface

---

## ✅ Basic Validation

The project uses simple beginner-level validation:
- Journal entry cannot be empty
- Search keyword cannot be empty
- Invalid menu choices show an error message
- Delete action asks for confirmation
- Missing journal file is handled
- File permission and other file errors are handled
